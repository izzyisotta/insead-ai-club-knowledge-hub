Setting up Claude Code MCP servers (the bits that actually break)

II Isabella Isotta · 22 March 2026 · 4 min read
#mcp-servers #setup #gotchas

MCP setup is one of those things where every individual step is fine, every individual step has a step that quietly went wrong without telling you, and the whole thing only works once they all line up. Here's the order I'd recommend and the bits that catch everyone the first time.

The four MCP servers worth installing day one

  • Playwright — browser automation. Lets Claude open URLs, click, fill forms, take screenshots.
  • Chrome MCP (Claude in Chrome) — different from Playwright. Drives your actual Chrome with your real session/cookies. Lets you skip auth chains.
  • OneNote / Microsoft 365 — read your INSEAD email, calendar, files. Quietly the biggest unlock.
  • Filesystem — read and write files. Ships with Claude Code, but check it's enabled.

The MCP config file

It's ~/.claude.json. Not ~/.cursor.json, not your project's .mcp.json. Servers go in the mcpServers object. Reading the wrong file is the #1 reason setups silently fail.

{
  "mcpServers": {
    "playwright": {
      "command": "npx",
      "args": ["@playwright/mcp"]
    }
  }
}

The five things that always break

  1. "Restart Claude Code" means quit fully (cmd+Q), not close the window. MCP servers register at startup. A reopened window still has the old state.
  2. Permissions on Mac. First Playwright run prompts for Accessibility access in System Settings. Grant it. If you didn't see the prompt, it's because your system muted it — go to Privacy & Security and add Claude Code manually.
  3. Browsers not installed. npm install -g @playwright/mcp doesn't install the browsers. npx playwright install does. Both are required.
  4. Chrome MCP is account-bound. The Claude browser extension only works if your Chrome account is the same as your Claude.ai account. Mismatched accounts fail silently.
  5. OneNote / MS365 needs OAuth. First connection opens a browser tab to authenticate. If you're on a corporate machine with extra MFA, this can take three attempts. Persist.

How to check it's working

Type into Claude Code: "open google.com and screenshot it". If a screenshot comes back, Playwright is good. If you get "I can't access the browser" — go back to the restart step.

For Chrome MCP: "what's on my current Chrome tab?". If it tells you, you're good.

For OneNote: "summarise my last 5 emails". If it asks you to sign in, sign in. If it then summarises, you're good.

Once it works

The world opens up. The first thing I built after MCP setup was the Canvas sync. Took an evening. Without MCP, would have taken a weekend.
