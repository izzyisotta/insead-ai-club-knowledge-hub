Morning vault audit: my /update skill

II Isabella Isotta · 30 March 2026 · 3 min read
#obsidian #claude-code #daily-ritual

Morning ritual. I run /update, Claude scans the whole vault for cross-referencing gaps, metadata inconsistencies, broken wikilinks, and unprocessed lecture sources, then groups everything by Critical / Warning / Info severity and auto-fixable / manual-review. Takes 90 seconds. Catches the rot before it accumulates.

No information should exist in only one place when the vault's rules say it should be reflected in multiple places.

The architectural insight

Single in-memory frontmatter index built once at the start, passed to four parallel agents (metadata linter, cross-reference checker, lecture source scanner, wikilink auditor). The vault is scanned once not four times. That's what makes it run in 90s instead of 5 minutes.

What it catches

  • People who exist in People/ but aren't referenced from the People Overview hub
  • Tasks with deadlines that have passed but status is still "active"
  • Lecture slides downloaded but not yet processed into a summary
  • Wikilinks pointing to renamed-or-moved files
  • Frontmatter values that don't match the approved-values list (single source of truth in Vault Metadata System.md)

The auto-fix protocol

Every finding is tagged auto-fixable or manual-review. Auto-fixes get a single confirmation prompt: "apply 17 fixes?" One yes, one batch, done. Manual items I work through individually.

What I added recently

A people-network checker that flags when someone has been added to a "People in Network" page but doesn't have an Industry tag in the main People Overview. Closes the loop on cross-referencing without me having to remember to do it.

Skill file: update.zip. Will need adapting to your own vault structure.
