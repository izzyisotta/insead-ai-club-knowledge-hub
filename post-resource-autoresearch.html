Why this matters

This is well worth staying close to. Andrej Karpathy, the godfather of AI, released a new GitHub repo which allows an agent to loop and self-improve on any task.

It's a ~630-line Python script that runs a tight loop:

  1. Agent reads program.md
  2. Modifies train.py
  3. Trains for 5 minutes on a single GPU
  4. Keeps the change if validation improves, reverts otherwise
  5. Repeat

Karpathy got 11% efficiency gain overnight. Shopify's CEO got 19% on a query-expansion model.

Constrained loop with measurable feedback. The pattern that actually works.

Why I'm sharing it for the AI Club

This is the cleanest case study for the Productive→Automation jump. It contrasts with Project Vend (Claudius the vending machine that hallucinated Venmo and tried a tungsten cube fire sale) to give the club a sharp diagnostic question:

How tightly is the problem constrained?

Tightly constrained + measurable feedback = automation works. Loose problem + unclear success criteria = open agent fails. Apply this lens before you build anything.

The repo: github.com/karpathy/autoresearch. Listen to the Startup Ideas episode for context.
