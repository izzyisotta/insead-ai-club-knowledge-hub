Canvas the Chrome way: yeah it's compute-heavy, here's why I went there anyway

CJ Chris Johnson · 18 April 2026 · 3 min read
#canvas #chrome-mcp #trade-offs

Pretty cool, going to set this up — that was the energy on the group chat after Isabella shared her Canvas Sync. I tried it. Hit walls. Tried Playwright. Didn't love it. Ended up using Chrome MCP through the actual session and I'm sticking with it.

Yeah, just chrome integration sadly. It's quite long / compute-intense. It also just works without me maintaining an auth chain.

Why not the Canvas API

Tried this first. The API exists but the token isn't easy to get hold of when you're not an admin, and even when you do the docs are out of date. Spent two hours, decided to try something else.

Why not Playwright

Played with Isabella's setup. It's elegant — but it requires me to keep an auth chain alive, deal with selector changes when ADFS swaps templates, and run an unattended Python script. Three things to maintain. Each one is a future headache.

What Chrome MCP gets you

  • Real session, real cookies. Whatever I'm logged into in Chrome is what Claude sees. No auth code at all.
  • It's a conversation, not a script. "Pull all the new readings from this week" works. "Pull all the new readings from this week and tag the ones from professors who actually grade tightly" also works.
  • Visual confirmation. You watch it happen in your real browser. If something looks wrong you stop it.

What it costs

  • Compute. Each interaction reads the page, plans, acts, reads again. A morning sync is maybe 3,000-5,000 tokens of context vs the negligible cost of an API call.
  • Time. 3-5 minutes for a sync that'd take Playwright 30 seconds.
  • Attention. Has to run while my Chrome is open. Can't be a 7:30am cron.

Why I prefer it anyway

I don't need it to run unattended at dawn. I need it to run when I sit down to study, in 90 seconds, while I make coffee. The trade-off goes the other way for that use case.

The honest version: Isabella's approach is engineering. Mine is a power-user prompt. Both work. Pick the one that matches how you actually live.
